# チェスパズル

8x8の盤面に並んだチェスの駒を動かして、同じ色の駒を3つ以上そろえて消すパズル。白も黒も動かせる。

## 遊び方

```sh
npm start   # http://localhost:8000 を開く
```

ES modules を使っているので、`index.html` を直接ダブルクリックしても動かない。必ずサーバー経由で開くこと。

## テスト・バランス計測

```sh
npm test              # ユニットテスト
npm run preview-combo # コンボ音を WAV に書き出して確認
npm run bench         # 消えやすさ・連鎖・スコアのざっくり計測
npm run simulate      # 大量自動プレイ（スコア分布・レア役の発生率）
npm run tune          # ノルマのパラメータを総当たり比較
npm run chain-growth  # 連鎖倍率を比較
```

調整用のパラメータは `src/rules.js` に集約してある。

## あそび方

初めて開くとチュートリアル（3ステップ: 動かす / 消す / ワイルド）が自動で始まる。
文章は無く、光る場所だけで伝える。
「あそび方」ボタンでいつでも見直せる。

## ルール

- 駒をタップすると、**選択中のマスが水色・移動できるマスが金色**にはっきり塗り分けられる
- 消えると**その場所に得点が浮かび上がる**（レア役は金色で大きく）
- **オーラの色が同じ駒どうしが3つ以上並ぶと消える**。ランクは色味、白黒は明るさで分かれる（明るい=白 / 濃い=黒）
- 移動できるのは**チェス本来の移動範囲にある「違う色の駒」のマス**だけ。間に駒があっても飛び越えられる
- ポーンだけは例外で、**斜め4方向**（前後どちらも）に取れる
- 取った駒は消え、動かした駒がいたマスは空く。空きマスは上から落ちてきて補充される
- **同じ色**の駒が縦か横に**3マス以上**連続し、**ランクが揃っていれば**消える（4マス以上ならまとめて消える）
- **クイーンとキングはワイルド**で、どのランクの代わりにもなる。ただし1つの並びに**1個まで**
- **ポーンは6ターン生き残るとワイルドに昇格する**（チェスのプロモーション）。消さずに守れば自分でワイルドを作れる
- 10秒操作が無いと、消せる手の駒をひとつ光らせる

### ランク

| ランク | 駒 |
|---|---|
| 1 | ポーン |
| 2 | ルーク / ビショップ / ナイト |
| ワイルド | クイーン / キング |

盤面は6×6。8×8のルールもコードには残っているが、選択肢からは外してある
（1手あたりの選択肢が263手あり多すぎたため。6×6は87手）。

### 駒の動き

ルール説明の中に**駒ごとの動き確認表**がある。実際の移動判定から自動生成しているので、
ルールを変えても表がズレない。

消える例: `111` `222` `11W` `W33` `WWW` / 消えない例: `112`（ランク混在） `1WW`（ワイルド2個）

### ノルマ

**5ターンごとにノルマ判定**があり、届かなければゲーム終了。ノルマはラウンドごとに15%上がる。
超過分は次のラウンドに繰り越されるので、大きく稼いだ分は貯金になる。

### スコア

- 一度に多く消すほど得（3マス45点 / 4マス80点 / 5マス125点）。縦横の同時消しは1つの大きなカタマリとして数える
- 連鎖するたびに倍率が1.5倍ずつ増える（5連鎖5.1倍 / 8連鎖17倍）
- **♛♚ ロイヤル**: クイーン・キングだけで3つ揃えると50倍。**♛ クイーンロイヤル / ♚ キングロイヤル**（単一種）なら400倍
- ロイヤルが出ると**盤面が一面ワイルドに変わって一掃される**（盤面とノルマのリセット）
- レア役が出ると**画面中央に名前が大きく表示される**
- ロイヤルが決まる手があるときは駒が金色に光る（20ターンに1回くらい来る）
